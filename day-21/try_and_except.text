try and except:
try:-
try block lets you to test the block of code for the errors
except:-
except block let you  handle the error 
else:-
else block is used to execute when there is no error 

example for try and except:-
try:
    print(x)
except:
    print("the is no data for x so except block is executed")


ex2:-
try:
    print(x)
except nameerror:
    print("except nameerror is executed")
except:
    print("the is no data for x so except block is executed")
