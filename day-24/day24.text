__init__()
class has built in method called __init__()
this init is written to do some operations inside a class

using __init__()
ex:-
class Dog:
    def __init__(self,name,age):
        self.name = name 
        self.age = age 


d1 = Dog("tommy",10)
print(d1)

ex2:-
class Dog:
    def __init__(self,name,age):
        self.name = name 
        self.age = age 

    def Animal(self):
        return f"hello i am {self.name} and i am {self.age} years old"

d1 = Dog("tommy",10)
print(d1.Animal())
