  if n <= 0:
    print("Done!")

    print(n)

generator:-
Generators are functions that can pause and resume their execution.

When a generator function is called, it returns a generator object, which is an iterato
ex:-
def count_up_to(n):
  count = 1
  while count <= n:
    yield count
    count += 1

for num in count_up_to(5):
  print(num)
