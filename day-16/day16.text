modules:- 
modules are files that are used to build your application
to create this files just create a file name with extension .py 
ex:-
step-1:-
my_modules.py 

def data(name): # function inside a module
    return "hello" + name 

names ={
    "name" : "manohar"
    "age" : 24
    "branch" : "cai"
}# dictionary inside a module 

step-2:-
now import the file 
ex:-
import my_modules

step-3:-
to use data present inside import module
we write as file_name.function_name (or) variable_name
ex:-
my_modules.data("manohar")
a = my_modules.names["name"]
print(a)

using from built in fulction:-
in my_module from my modules there are two datas one is function and another one is dictionary

ex:-
