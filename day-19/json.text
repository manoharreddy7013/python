converting the data from python to json using json.dump
import json 
x = {
    "name":"manohar",
    "age":24,
    "branch":"cai",
    "grade":"c"
}
y = json.dump(x)

Example
Convert Python objects into JSON strings, and print the values:

import json

print(json.dumps({"name": "John", "age": 30}))
print(json.dumps(["apple", "bananas"]))
print(json.dumps(("apple", "bananas")))
print(json.dumps("hello"))
print(json.dumps(42))
print(json.dumps(31.76))
print(json.dumps(True))
print(json.dumps(False))
print(json.dumps(None))

indent:-
indent in json is used to provide space in begining of every line
ex:-
x = {
    "name":"manohar",
    "age":24,
    "branch":"cai",
    "grade":"c"
}
y = json.dump(x,indent=4)
print(y)

seperators:-
used to seperate the data using , or provided symbols
ex:-
x = {
    "name":"manohar",
    "age":24,
    "branch":"cai",
    "grade":"c"
}
y = json.dump(x,seperator=(":",":"))
print(y)
